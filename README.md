# Vampire Survivors Mod Pack

Mod pack สำหรับเล่นกับเพื่อน: ช่องอาวุธ/passive เพิ่ม (More Slots Online), หน้าเว็บ Live Grimoire (evolution, ดาเมจ, แผนที่), แถบเลือดบอส, ภาษาไทย
ใช้ได้ทั้งเล่นคนเดียวและเล่นออนไลน์

## ลงครั้งแรก
1. ปิดเกม
2. ไปที่ [Releases ล่าสุด](https://github.com/bookbang285/vs-modpack/releases/latest) โหลด `B###_VampireSurvivors-ModPack-Coop.zip`
3. แตก zip แล้วก๊อปโฟลเดอร์ `Vampire Survivors` ทับโฟลเดอร์เกม (Steam → คลิกขวาเกม → Manage → Browse local files) กดเขียนทับทั้งหมด
4. ดับเบิลคลิก `Play-VS-ModPack.bat` ในโฟลเดอร์เกม ครั้งแรกจะสร้างทางลัด **Vampire Survivors (mod)** บน Desktop ให้

## อัปเดต
เปิดเกมจากทางลัด **Vampire Survivors (mod)** ทุกครั้ง ถ้ามี mod ใหม่จะโหลดเอง (เฉพาะไฟล์ที่เปลี่ยน ไม่ทับการตั้งค่า) แล้วเปิดเกมให้
ถ้าเกมเปิดค้างอยู่จะไม่อัปเดต ให้ปิดเกมก่อนแล้วกดใหม่

เช็กเวอร์ชันที่ลงอยู่: เปิดไฟล์ `BepInEx\modpack-build.txt`

## ข้างใน
BepInEx 6 (IL2CPP), XUnity.AutoTranslator (คำแปลไทย), More Slots Online, Live Grimoire, Equipment Level Badges, Coop Level-Up Fix
